osm-source.osm is the original OSM API extract. map.json is its projected,
clipped derivative, distributed under the same ODbL terms. Road widths and
untagged heights are stylized estimates, not surveyed measurements.
The destination POI is independently resolved from Yandex Maps; it is not
an assertion that OSM contains the Avadh Complex outline or first-floor entrance.
No navigation route is supplied. The red animation follows an existing road way.
